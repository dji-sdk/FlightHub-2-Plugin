# 安装与复验

这页只做三件事：安装 Skill、确认客户端加载成功、检查开发环境是否就绪。

## 1. 安装完整 Skill

源码：<https://github.com/dji-sdk/FlightHub-2-Plugin>（Skill 随源码提供）。

先取得插件开发工具完整源码。Skill 随源码提供，位于 `skills/fh2-plugin-dev/`；SDK 位于 `packages/fh2-plugin-sdk/`，无需另找下载包。Skill 无需人工复制到客户端目录。

本页使用第三方安装器 `skills@1.7.4`，要求 **Node.js 22.20 或更高**。这高于 FH2 开发工具本身的最低 Node 20.19；`npx` 首次运行需要下载安装器及其依赖。安装 Skill 不需要先构建 FH2 工具链。

安装前检查项目和客户端中的已有 `fh2-plugin-dev` 副本，先备份需要保留的定制。安装器会提示 `overwrites:` 并覆盖同名目标目录，不合并定制，也不自动清理历史安装位置。

在**目标项目根目录**打开终端，设置已解压的开发工具路径：

```sh
export FH2_TOOLS="<已解压的开发工具绝对路径>"
```

按当前客户端执行一条命令：

```sh
# OpenCode
npx skills@1.7.4 add "$FH2_TOOLS/skills/fh2-plugin-dev" --skill fh2-plugin-dev --agent opencode --copy

# Claude Code
npx skills@1.7.4 add "$FH2_TOOLS/skills/fh2-plugin-dev" --skill fh2-plugin-dev --agent claude-code --copy
```

交互时选择 **Project**（仅当前项目），核对安装摘要和覆盖提示，再确认安装。如询问是否另装 `find-skills`，选择 **No**，本页只安装 `fh2-plugin-dev`。安装器可能保存自己的用户级提示状态；项目级选择限定的是本 Skill 的安装范围。

安装器复制整个 Skill，包括：

```text
fh2-plugin-dev/
|-- SKILL.md
|-- references/
`-- scripts/resolve-env.cjs
```

| 客户端 | 本页命令的项目安装目录 |
| --- | --- |
| OpenCode | `<项目>/.agents/skills/fh2-plugin-dev/` |
| Claude Code | `<项目>/.claude/skills/fh2-plugin-dev/` |

项目根还会生成 `skills-lock.json`，记录本地来源和内容摘要。保留源码目录，便于后续按锁记录恢复；不要在 Skill 目录外再套一层同名文件夹。

仍在目标项目根执行对应命令，确认列表中有 `fh2-plugin-dev` 及实际目录：

```sh
npx skills@1.7.4 list --agent opencode
# Claude Code 对应使用：
npx skills@1.7.4 list --agent claude-code
```

文件安装和列表可见不代表客户端已经加载，继续做下一节复验。

## 2. 重启客户端并验证

重启客户端，新开一个对话：

```text
请加载 fh2-plugin-dev，确认 SKILL.md、references/ 和 scripts/resolve-env.cjs 都可读。
只做安装复验，不创建插件、不下载依赖。
```

能读到文件才算加载成功。再试一句：

```text
给驾驶舱加个工具栏按钮。
```

正确行为是先问功能和使用页面，而不是直接创建工程。

## 3. 检查开发环境

在已确认的工程目录运行（路径换成实际值）：

```sh
node "<Skill目录>/scripts/resolve-env.cjs" --project "<工程目录>" --platform-root "<开发者工具目录>"
```

| 状态 | 含义 |
| --- | --- |
| `ready` | 已找到工具包，运行数据的 manifest 最小探测通过；仍需实际校验和读取数据 |
| `bootstrap_required` | 缺少 Toolchain，先补齐；需求澄清仍可继续 |
| `node_upgrade_required` | Node 版本低于要求（最低 20.19，推荐 22 LTS） |
| `broken_environment` | 包或数据损坏，修复对应的本地副本 |

还没有开发者工具时省略 `--platform-root`。

## 4. 初始化开发者工具（如需要）

先按[环境准备](../30.detailed-guide/20.development/40.hands-on/10.environment-preparation.md#需要装什么)检查 Node 和 pnpm 10.15.0；pnpm 命令不可用时，按该页的 Corepack 步骤准备命令入口。版本检查通过后，在开发者工具根目录执行：

```sh
pnpm install --frozen-lockfile
pnpm build:tooling
node packages/fh2-plugin-toolchain/bin/fh2-plugin.mjs --help
```

能看到帮助输出说明工具可用。全局注册 `fh2-plugin` 命令是可选的，不影响 AI 使用本地 bin。

## 核对

- [ ] 探针状态和实际工具路径已记录
- [ ] 没有把 `ready` 当成页面或业务已验证
