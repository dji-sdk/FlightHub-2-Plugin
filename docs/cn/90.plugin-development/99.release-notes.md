# 发版说明

## 1.0.0

发布日期：2026-10-27

发行内容：FH2 插件开发工具 1.0.0

### 本次发布

- 插件模型：前端成员、后端成员和共享契约可以组成一个业务能力，分别构建、一起交付。
- 前端插件：四类宿主（驾驶舱、计划库、项目页面、消息中心）、扩展点、宿主能力和界面生命周期。
- 后端插件：HTTP 接口、事件消费、流程编排、数据存储、缓存、受管出网、外部连接和前端通知。
- 工具链：创建、生成类型、校验、构建、打包、本地调试、Web IDE、工作流画布和 MCP 接入。
- 本地调试页面：覆盖前端多宿主装载和本地 HTTP/事件模拟，便于在没有真实设备时完成第一轮验证。
- AI 开发 Skill：用自然语言描述需求，AI 协助查能力、改代码、补测试并报告实际执行结果。
