# 后端开发深度指南

后端插件用 TypeScript 编写：写接口脚本、消息回调、流程编排，工具链负责编译打包，宿主负责加载和调用。按当前问题选择页面，不必先读完整章：

1. [后端插件的结构](./00.package-structure.md)——目录里放什么、源码和构建产物是什么关系
2. [源清单 fh2-plugin.json](./10.plugin-json.md)——全部字段说明
3. [HTTP 接口](./20.http-handler.md)——对外接口的写法与错误处理
4. [消息订阅](./30.event-handler.md)——订阅平台消息并自动执行
5. [ctx 与能力注入](./40.context-and-allowlist.md)——脚本能用什么、怎么申报
6. [数据存储与缓存](./50.data-store.md)——store 六方法与 cache 用法
7. [流程编排](./60.workflow.md)——多步骤异步任务的写法
8. [流程编排练习](./65.workflow-hands-on.md)——在画布上跑通 `example-flow`，预检后到目标环境验证
9. [触发方式](./70.triggers.md)——五种启动流程的方式
10. [连接外部系统](./80.external-connections.md)——受管出网与连接配置

先看到插件面板，走[快速入门](../../../10.quick-start/00.index.md)；需要建立后端工程并练习接口、存储与本地调用，做[第一个后端插件完整教程](../40.hands-on/30.first-backend-plugin.md)。完整教程不是短入门，也不证明目标环境的流程或外部依赖已就绪。
