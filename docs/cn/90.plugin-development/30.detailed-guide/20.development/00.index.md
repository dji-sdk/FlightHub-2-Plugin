第一次只想打开插件，先做[五步快速入门](../../10.quick-start/10.first-plugin.md)。需要逐文件理解接线时，选择下面的完整练习：

- [环境准备](./40.hands-on/10.environment-preparation.md)：插件化开发者工具、安装、构建与可选 CLI 注册。
- [前端插件](./40.hands-on/20.first-frontend-plugin.md)：按钮、面板、状态与释放。
- [后端插件](./40.hands-on/30.first-backend-plugin.md)：接口、存储和预期失败。
- [全栈插件](./40.hands-on/40.first-fullstack-plugin.md)：前端调用后端，核对进程内数据与真实持久化的区别。
