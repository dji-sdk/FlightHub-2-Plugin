## 一条插件的完整链路

```text
fh2-plugin.json（插件清单，你写）
  -> fh2-plugin generate      （按清单生成类型文件）
  -> src/plugin.ts            （入口代码，你写）
  -> src/hosts/<host>/activate.ts（各页面的激活逻辑，你写）
  -> 界面契约 + Vue 组件       （你写）
  -> fh2-plugin build         （构建出 dist/ 产物）
  -> dist/fh2-plugin.json     （构建产物清单，工具链生成）
```

左边是你维护的源码，最后一步生成的 `dist/` 是交给平台安装的产物。不要反向修改 `dist/` 里的任何文件。

## 日常习惯

每改一次清单或代码，至少跑一遍：

```bash
pnpm run generate
pnpm run validate
pnpm run tsc
pnpm run build
```

四条都通过再进下一步。出错了先修第一条诊断，再继续。
