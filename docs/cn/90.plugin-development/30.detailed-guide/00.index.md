# 开发指南

已有工程或明确需求时，按正在做的任务查对应章节。这里集中概念、开发写法、功能、调试、示例、交付和 API，选择需要的一项即可。

## 按任务找内容

| 你现在要做什么 | 从这里进入 | 重点看什么 |
| --- | --- | --- |
| 分清插件、业务能力和运行位置 | [插件概念](./10.concepts/00.index.md) | 行业工作区、能力扩展、宿主、扩展点和界面的分工 |
| 完整练习前端、后端或全栈接线 | [完整练习](./20.development/00.index.md#完整练习) | 从开发者工具开始，逐文件修改并核对运行结果 |
| 添加按钮、面板或计划表单区域 | [前端开发](./20.development/10.frontend/00.index.md) | 清单声明、入口贡献、界面通信和生命周期 |
| 增加接口、保存记录或编排自动流程 | [后端开发](./20.development/20.backend/00.index.md) | 接口与事件入口、权限、存储和流程触发 |
| 让前后端完成同一项业务 | [前后端协作](./20.development/30.fullstack/00.index.md) | 数据约定、重复请求、推送与最终状态 |
| 查地图、设备、媒体等功能能否使用 | [能力总览](./30.features/00.index.md) | 所属运行侧、权限和提供条件 |
| 定位按钮不出现、请求失败或状态不更新 | [调试与测试](./40.debug-and-test/00.index.md) | 本地模拟、真实前端接入和目标环境验证 |
| 找接线写法或理解业务组合 | [示例与案例](./50.examples/00.index.md) | 示例类型、前置条件和验证范围 |
| 校验、打包并交付插件 | [构建、交付与安全](./60.delivery-and-security/00.index.md) | 源码、构建产物、上传包和安装升级 |
| 精确查字段、方法或命令参数 | [API 参考](./70.api-reference/00.index.md) | 当前契约的语法和调用语义 |

按错误码排查时看[错误码](./80.error-codes.md)；不理解术语时查[术语表](./90.glossary.md)；
常见疑问见[FAQ](./95.faq.md)。

## 先动手还是先查业务

还没打开过插件面板，先做[快速入门](../10.quick-start/00.index.md)。想判断自己的业务能做成什么样，先看[典型场景](../01.what-plugins-can-do.md)，再按上表选择开发任务。

## 使用范围

各章使用与手册配套的开发者工具。接口和命令查 API 参考，操作步骤查指南；示例按其标明的类型、依赖和验证范围使用。接入真实设备或后端流程时，还需确认目标产品、权限、安装及运行条件，本地界面可操作不代表整项业务已经验收。
