# 示例与案例总览

从最小可用到真实业务的示例解读。每个示例标注类型：可运行示例表示本页明确列出的链路可配合模板运行；集成示例讲代码与契约要点，可能需要目标环境验证。混合示例会分别列出可运行部分与阻塞边界：

| 示例 | 类型 | 展示什么 |
| --- | --- | --- |
| [最小前端插件](./10.minimal-frontend-plugin.md) | 集成示例 | 项目侧边栏入口 + 自定义页面 |
| [消息告警卡片](./11.message-alert.md) | 可运行示例 | `message.alert-popups` 扩展点 |
| [计划表单扩展](./12.plan-form.md) | 集成示例 | `plan.form-extensions` 的校验与提交 |
| [驾驶舱动作](./13.cockpit-action.md) | 集成示例 | 工具栏按钮 + 展开面板 + 资源管理 |
| [最小后端插件](./20.minimal-backend-plugin.md) | 可运行示例（接口服务与凭据就绪后） | 源清单 + 一个接口 + 构建；HTTP 诊断需要已启用的服务和插件网关凭据 |
| [最小全栈插件](./30.minimal-fullstack-plugin.md) | 可运行示例（界面/HTTP）+ 集成示例（媒体事件） | `dev` 运行、重置为空数据后可完成单问题上报、签收、完成；列表最多 20 条，媒体输入与排序见支持边界 |
| [多宿主插件](./35.multi-host.md) | 集成示例 | 同一插件服务四个宿主 + 插件服务 |
| [事故快处](./40.accident-response.md) | 业务案例 | 事件驱动流程 + 人在环信号的真实业务（依赖目标环境） |
| [交通违法抓拍](./50.traffic-capture.md) | 业务案例 | 前端深水区 + 大型后端插件：直播画布标注、SEI 检测帧、设备状态门控，以及 13 接口 + 2 类事件（3 个消费入口） + 6 实体（依赖目标环境） |
| [违停巡逻完整案例](./55.patrol-case.md) | 业务案例 | 示教、计划配置、初检复检、照片回顾和返航决策的完整用户旅途（依赖目标环境） |

> 集成示例按本页说明的前置条件和目标契约使用，不代表所有代码可直接在本地模拟器跑通。界面接线可参照[消息告警卡片](./11.message-alert.md)或[第一个全栈插件](../20.development/40.hands-on/40.first-fullstack-plugin.md)的三件套写法。业务案例依赖目标环境的外部资产，不能在本地完整复现。

示例依赖的工具链与模板获取方式见[环境准备](../20.development/40.hands-on/10.environment-preparation.md)，模块示意名不是 npm 安装名。`build` / `pack` 不启动服务；首次调用优先使用全栈界面的受管通道，独立 curl 仅在接口服务与网关鉴权配置具备后用于诊断。
