# 项目侧边栏与工作区

这个示例在项目侧边栏加一个入口，点击进入自己的路由页面；还可以选择再往右侧主内容区挂一块工作区界面。用到的是 `project.sidebar-actions` 扩展点。

> `fh2-plugin-sdk` 是插件开发 SDK；下文模块名用于说明，实际导入路径保留生成工程配置。模块名不表示已发布的 npm 包名。

## 这个示例做什么

- 项目侧边栏出现一个图标按钮，宿主加载贡献后注册动态路由（如 `/dispatch-demo`）；点击入口后挂载你的界面。
- 界面是一张表单，可以提交数据。
- 通过清单配置开关，再向路由对应的右侧主内容区挂一个只读工作区界面——这是同一个扩展点上的可选字段 `renderWorkspace`，不是第二个扩展点。

## 关键代码讲解

### 清单：声明扩展点、路由和界面

`fh2-plugin.json`：

```json
{
  "id": "exp_sidebar_demo",
  "name": "侧边栏示例",
  "version": "0.1.0",
  "entry": "./plugin.js",
  "permissions": ["platform:http"],
  "extensions": [
    {
      "id": "dispatch-sidebar-action",
      "point": "project.sidebar-actions",
      "path": "/dispatch-demo",
      "position": 2
    }
  ],
  "contributes": {
    "icons": [{ "id": "plugin", "src": "./icons/plugin.svg" }]
  },
  "views": {
    "dispatch-form": { "entry": "./views/dispatch-form.js" }
  },
  "config": {
    "enableWorkspace": {
      "type": "boolean",
      "default": false,
      "label": "启用工作区测试渲染"
    }
  }
}
```

- `path` 会被项目宿主注册为动态路由。
- `position` 控制插入原生侧栏的位置。
- `config` 是插件配置项，用户可在宿主的插件设置里修改，代码里通过 `ctx.config` 读取。

### 入口：贡献侧栏入口和界面会话

```ts
// src/plugin.ts
import { createViewState, definePlugin } from 'fh2-plugin-sdk'
import { dispatchFormView } from './views/dispatch-form/contract'
import type { AppProjectContext } from './generated/plugin-types'
import type { DispatchFormState } from './views/dispatch-form/contract'

export default definePlugin({
  async activate (rawCtx) {
    if (rawCtx.host.id !== 'project')
      return
    const ctx = rawCtx as AppProjectContext
    const state = createViewState<DispatchFormState>({
      submitting: false,
      lastEventId: null,
      error: null,
    })

    // 注册界面会话：界面通过通信通道调用 dispatch 方法
    await dispatchFormView.handle(ctx, {
      state,
      methods: {
        dispatch: async (input: { address: string; lat: number; lng: number }) => {
          state.update(current => ({ ...current, submitting: true, error: null, lastEventId: null }))
          try {
            if (!input.address.trim() || !Number.isFinite(input.lat) || !Number.isFinite(input.lng)
              || Math.abs(input.lat) > 90 || Math.abs(input.lng) > 180) {
              throw new Error('请填写地址和有效经纬度')
            }
            const res = await ctx.apiCall<{ code: number; message: string; data?: { eventId: string } }>(
              '/plugin-scene/data-store/events',
              {
                method: 'POST',
                body: {
                  eventType: '警情',
                  source: 'demo',
                  priority: 'low',
                  status: 'unacknowledged',
                  poi: { lat: input.lat, lng: input.lng },
                  notifyOn: ['unacknowledged'],
                  rawPayload: { address: input.address, lat: String(input.lat), lng: String(input.lng) },
                },
              },
            )
            const eventId = res.data?.eventId
            if (!eventId)
              throw new Error('响应缺少事件 ID，不能确认提交成功')
            state.update(current => ({ ...current, submitting: false, lastEventId: eventId }))
          } catch (error) {
            state.update(current => ({
              ...current,
              submitting: false,
              error: error instanceof Error ? error.message : '提交失败',
            }))
          }
        },
      },
    })

    // 贡献侧栏入口；配置打开时额外挂工作区
    const workspaceEnabled = ctx.config.enableWorkspace === true
    await ctx.extensions.contribute('dispatch-sidebar-action', {
      icon: 'plugin', // 图标 ID 需在清单 contributes.icons 声明
      label: '警情派遣示例',
      disabled: false,
      render: () => dispatchFormView.get(ctx),
      ...(workspaceEnabled
        ? { renderWorkspace: () => dispatchFormView.get(ctx) }
        : {}),
    })
  },
})
```

要点：

- `render` 返回左侧表单界面；`renderWorkspace` 是可选字段，真实宿主在路由命中时才调用它挂主内容区。
- `renderWorkspace` 挂载失败或缺失时只显示左侧界面，不要让它导致整个插件激活失败。
- 离开路由、贡献消失或宿主卸载时，宿主会自动释放界面挂载。

### 界面契约与组件

```ts
// src/views/dispatch-form/contract.ts
import { definePluginView } from 'fh2-plugin-sdk'

export interface DispatchFormState {
  readonly submitting: boolean;
  readonly lastEventId: string | null;
  readonly error: string | null;
}

export const dispatchFormView = definePluginView<{
  state: DispatchFormState;
  methods: {
    dispatch: (input: { address: string; lat: number; lng: number }) => Promise<void>;
  };
}>('dispatch-form')
```

本页不省略界面接线。下面两个文件都要新建；`index.ts` 挂载并释放 Vue，`DispatchForm.vue` 显示表单和失败提示。

### 界面入口：src/views/dispatch-form/index.ts

```ts
import { createApp, reactive } from 'vue'
import { defineView } from 'fh2-plugin-sdk'
import { dispatchFormView } from './contract'
import type { DispatchFormState } from './contract'
import DispatchForm from './DispatchForm.vue'

export default defineView({
  mount (ctx) {
    const state = reactive<DispatchFormState>({ submitting: false, lastEventId: null, error: null })
    const client = dispatchFormView.client(ctx.port)
    const subscription = client.state.subscribe(next => Object.assign(state, next))
    const app = createApp(DispatchForm, {
      state,
      onDispatch: (input: { address: string; lat: number; lng: number }) => client.dispatch(input),
    })
    app.mount(ctx.mountElement)
    return {
      dispose () {
        subscription.dispose()
        client.dispose()
        app.unmount()
      },
    }
  },
})
```

### 界面组件：src/views/dispatch-form/DispatchForm.vue

```vue
<script setup lang="ts">
import { ref } from 'vue'
import type { DispatchFormState } from './contract'

const props = defineProps<{
  state: DispatchFormState;
  onDispatch: (input: { address: string; lat: number; lng: number }) => Promise<void>;
}>()
const address = ref('测试地点')
const lat = ref('0')
const lng = ref('0')
const localError = ref('')

async function submit () {
  localError.value = ''
  try {
    await props.onDispatch({ address: address.value, lat: Number(lat.value), lng: Number(lng.value) })
  } catch {
    localError.value = '界面连接已失效，请重新打开插件页面'
  }
}
</script>

<template>
  <form class="dispatch-form" @submit.prevent="submit">
    <h2>警情派遣示例</h2>
    <label>地址 <input v-model="address" required></label>
    <label>纬度 <input v-model="lat" type="number" step="any" min="-90" max="90" required></label>
    <label>经度 <input v-model="lng" type="number" step="any" min="-180" max="180" required></label>
    <button type="submit" :disabled="state.submitting">
      {{ state.submitting ? '提交中…' : '提交' }}
    </button>
    <p v-if="state.lastEventId">
      已创建：{{ state.lastEventId }}
    </p>
    <p v-if="state.error || localError" role="alert">
      {{ state.error || localError }}
    </p>
  </form>
</template>

<style scoped>
.dispatch-form { display: grid; gap: 12px; padding: 20px; color: #172033; background: #fff; }
label { display: grid; gap: 4px; }
input, button { padding: 8px; }
[role="alert"] { color: #b42318; }
</style>
```

### 失败与状态单测：tests/dispatch.test.ts

新建测试文件。以下模拟业务接口的成功和失败，不调用真实事件中心：

```ts
import { describe, expect, it, vi } from 'vitest'
import type { PluginContext } from 'fh2-plugin-sdk'
import type { DispatchFormState } from '../src/views/dispatch-form/contract'
import plugin from '../src/plugin'

const captured = vi.hoisted(() => ({ session: undefined as any }))
vi.mock('../src/views/dispatch-form/contract', () => ({
  dispatchFormView: {
    handle: async (_ctx: unknown, session: unknown) => {
      captured.session = session
    },
    get: () => ({}),
  },
}))

describe('派遣表单', () => {
  it('成功取业务 ID；请求失败与无效输入不能显示成功', async () => {
    const apiCall = vi.fn().mockResolvedValue({ code: 0, message: 'success', data: { eventId: 'test-event' } })
    const ctx = { host: { id: 'project' }, config: { enableWorkspace: false }, apiCall, extensions: { contribute: vi.fn().mockResolvedValue({ dispose: vi.fn() }) } } as unknown as PluginContext
    await plugin.activate(ctx)
    const session = captured.session as { state: { get: () => DispatchFormState }; methods: {
      dispatch: (input: { address: string; lat: number; lng: number }) => Promise<void>;
    }; }
    await session.methods.dispatch({ address: '测试地点', lat: 0, lng: 0 })
    expect(session.state.get()).toMatchObject({ submitting: false, lastEventId: 'test-event', error: null })
    apiCall.mockRejectedValueOnce(new Error('请求失败'))
    await session.methods.dispatch({ address: '测试地点', lat: 0, lng: 0 })
    expect(session.state.get().error).toBe('请求失败')
    await session.methods.dispatch({ address: '', lat: 0, lng: 0 })
    expect(session.state.get().error).toBe('请填写地址和有效经纬度')
    expect(apiCall).toHaveBeenCalledTimes(2)
  })
})
```


## 怎么在本地跑起来

先完成[环境准备](../20.development/40.hands-on/10.environment-preparation.md)。本页用完整接线练习项目侧栏；本地可验证表单、源码和失败提示，成功创建业务事件仍依赖目标环境已提供相应接口，右侧工作区也要在真实宿主验收。

创建后在 `exp_sidebar_demo/` 工程根操作，路径均相对该目录：

| 文件或目录 | 操作 |
| --- | --- |
| `fh2-plugin.json`、`src/plugin.ts` | 用上方内容整文件替换 |
| `src/views/dispatch-form/` 中三个文件 | 逐个新建，复制对应完整内容 |
| `public/icons/plugin.svg` | 新建图标 |
| `tests/dispatch.test.ts` | 新建本页测试 |
| `src/hosts/cockpit/`、`src/views/hello-panel/`、`src/views/issue-panel/`、`src/views/issue-dialog/` | 删除本次新工程内的原演示；它们引用旧清单，不保留为本页依赖 |
| 原 `tests/contract.test.ts`、`tests/issue-activate.test.ts` | 删除旧驾驶舱示例测试，由本页测试覆盖新功能 |
| `package.json`、构建配置、`tsconfig.json`、`vitest.config.ts` | 保持原样；不要手改生成类型 |

删除操作仅针对本次新工程，不对已有业务工程执行。需要改造已有工程时先比较并保留它自己的代码与测试。

在确认的业务父目录运行创建向导，选择「1=前端插件」，Plugin ID 输入 `exp_sidebar_demo`，其余项按默认值确认并选择立即安装。命令只要求终端能直接运行 `fh2-plugin`；未注册全局 CLI 时，把它替换为开发者工具目录中 `packages/fh2-plugin-toolchain/bin/fh2-plugin.mjs` 的实际路径：

```bash
fh2-plugin create
cd exp_sidebar_demo
# 按上表完成文件替换、新建和原演示清理后再执行检查
pnpm run generate
pnpm run validate
pnpm run test
pnpm run tsc
pnpm run lint
pnpm run build
pnpm exec fh2-plugin dev --frontend-only
```

验证步骤：

1. 打开本地调试页面，切到项目区，侧边栏出现"警情派遣示例"。
2. 点击进入 `/dispatch-demo`，左侧表单正常渲染。
3. 本地接口未提供时，点击提交应显示错误而不是显示成功；输入非法坐标时先显示校验提示。实际成功请求须在目标环境检查返回的事件 ID。
4. 在插件配置里把"启用工作区测试渲染"打开并重载：本地调试页面只消费左侧 `render`，工作区要用真实宿主验证：

```bash
pnpm exec fh2-plugin preview --fh2-url http://<支持插件调试的私有化环境地址>/project
```

真实宿主预览仅支持 HTTP 私有化环境，且需要浏览器已登录并进入目标项目。进入调试面板、手填本次资源根并完成校验和同意后，再打开 `/dispatch-demo` 验证左右两个区域。

## 常见问题

| 现象 | 原因与处理 |
|---|---|
| 侧栏入口不出现 | 当前不是项目宿主、插件未启用，或激活时报错（看诊断面板） |
| 本地调试页面里左侧有表单、右侧为空 | 正常：本地调试页面不消费 `renderWorkspace`，需真实宿主预览 |
| 真实宿主右侧也为空 | 配置开关没打开，或宿主未注入工作区桥 |
| 提交返回 404 | 对接的事件中心接口在该环境不可用；本地联调属预期 |
| 经纬度校验报错 | 只接受普通十进制数，纬度 -90~90、经度 -180~180 |
