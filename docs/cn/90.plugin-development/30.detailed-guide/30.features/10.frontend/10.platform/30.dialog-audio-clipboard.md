# 弹窗、音频与剪贴板

这三个能力都由主应用提供，四个宿主都能用：弹一个自定义内容的对话框、播放提示音、写剪贴板。清单里分别声明 `platform:dialog`、`platform:audio`、`platform:clipboard` 权限，代码里 `await ctx.capabilities.get(...)` 获取并判空。

> `fh2-plugin-sdk` 是插件开发 SDK；下文模块名用于说明，实际导入路径保留生成工程配置。模块名不表示已发布的 npm 包名。

## `platform:dialog`：弹出自定义对话框

| 项 | 值 |
| --- | --- |
| 权限名 | `platform:dialog` |
| 方法 | `open(view, options?): Promise<ViewPresentation>` |
| `options` | `title?`、`width?`、`height?`、`hideHeader?` |
| presentation | `close()`、`closed: Promise<void>` |

`view` 参数是插件界面句柄，用 `incidentDialog.get(ctx)` 获得；界面的定义见[界面与状态](../../../20.development/10.frontend/40.view-and-state.md)。

```ts
const presentation = await dialog.open(incidentDialog.get(ctx), {
  title: '事件坐标',
  width: 560,
  height: 280,
})
```

行为与限制：

- 同类弹窗"新的顶掉旧的"：新弹窗打开前先关闭旧弹窗。
- 宽度缺省 720 px，最小 320 px，且不超过视口宽减 56 px；高度最小 100 px。不要在界面里假设固定尺寸。
- 点击遮罩不关闭，按 ESC 会关闭。
- `hideHeader: true` 会同时隐藏标题和关闭按钮，此时界面必须自己提供关闭操作。
- 主动 `close()`、宿主关闭、宿主卸载都会卸载界面；`presentation.closed` 可用来同步业务状态。

## `platform:audio`：播放音频

| 项 | 值 |
| --- | --- |
| 权限名 | `platform:audio` |
| 方法 | `createPlayer({ source, volume?, loop? }): Player` |
| 播放器方法 | `play({restart?})`、`pause()`、`stop()`、`setVolume({volume})`、`setLoop({loop})`、`dispose()` |

`source` 支持三种：

```ts
{ type: 'preset', sound: 'warning' }            // 内置音：warning / shutter / record-start / record-stop
{ type: 'url', url: 'https://example.com/a.mp3' } // 绝对 HTTP(S) 或 base64 data:audio
{ type: 'plugin', path: './static/audio/notice.mp3' } // 相对插件资源根
```

限制：

- 音量必须是 `0..1` 的有限数。
- 普通 URL 最长 16,384 字符，data URL 最长 1,500,000 字符；不能带用户名密码。
- 非 data URL 会以 `crossOrigin=anonymous` 加载，服务端需配置 CORS。
- 浏览器可能阻止没有用户手势的自动播放——把 `play()` 放在用户点击的回调里。
- `stop()` 回到 0 秒，`pause()` 保留进度；`dispose()` 幂等，释放后继续操作会失败。

## `platform:clipboard`：写剪贴板

| 项 | 值 |
| --- | --- |
| 权限名 | `platform:clipboard` |
| 方法 | `writeText({ text: string })`（插件侧调用返回 `Promise<void>`） |

```ts
await clipboard.writeText({ text: '22.543096,114.057865' })
```

只写纯文本：不支持读取、HTML 或图片。写入失败会抛错，业务上应保留可手动选中的文本作为降级。

## 集成片段

先按[第一个前端插件](../../../20.development/40.hands-on/20.first-frontend-plugin.md)建立可运行工程。下面不是完整的 `fh2-plugin.json`，不可整份替换：将 `permissions` 去重合并、`views` 按 ID 合并到现有清单，保留现有宿主扩展、界面声明/注册和入口。权限不会触发激活；清单若只有 `extensions: []`，`activate()` 不会执行。

合并到 `fh2-plugin.json` 的字段：

```json
{
  "permissions": [
    "platform:dialog",
    "platform:audio",
    "platform:clipboard"
  ],
  "views": {
    "incident-dialog": { "entry": "./views/incident-dialog.js" }
  }
}
```

下面的 `definePlugin` 只示范入口逻辑组织，不是可直接替换完整工程的入口；保留生成工程的 SDK 导入路径，将能力逻辑合入已有 `activate` 和业务收尾，保留原有扩展贡献与界面注册。还需提供 `incident-dialog` 的界面入口和界面按钮，按[界面与状态](../../../20.development/10.frontend/40.view-and-state.md)将按钮接到这里注册的方法。

```ts
// plugin.ts
import {
  createViewState,
  definePlugin,
  definePluginView,
} from 'fh2-plugin-sdk'

interface IncidentDialogContract {
  state: { coordinates: string; copied: boolean }
  methods: {
    copyCoordinates(): void
    playWarning(): void
    close(): void
  }
}

const incidentDialog = definePluginView<IncidentDialogContract>('incident-dialog')

export default definePlugin({
  async activate (ctx) {
    const [dialog, audio, clipboard] = await Promise.all([
      ctx.capabilities.get('platform:dialog'),
      ctx.capabilities.get('platform:audio'),
      ctx.capabilities.get('platform:clipboard'),
    ])
    if (!dialog || !audio || !clipboard) {
      ctx.logger.warn('事件工具依赖的主应用能力不完整')
      return
    }

    const player = await audio.createPlayer({
      source: { type: 'preset', sound: 'warning' },
      volume: 0.6,
      loop: false,
    })
    let presentation: Awaited<ReturnType<typeof dialog.open>> | undefined
    const state = createViewState({
      coordinates: '22.543096,114.057865',
      copied: false,
    })

    await incidentDialog.handle(ctx, {
      state,
      methods: {
        async playWarning () {
          // 界面内按钮点击调用，满足浏览器用户手势要求。
          await player.play({ restart: true })
        },
        async copyCoordinates () {
          try {
            await clipboard.writeText({ text: '22.543096,114.057865' })
            state.update(current => ({ ...current, copied: true }))
          } catch (error) {
            ctx.logger.warn('复制失败，请在界面中展示可选中文本', {
              message: error instanceof Error ? error.message : String(error),
            })
          }
        },
        async close () {
          await presentation?.close()
        },
      },
    })

    presentation = await dialog.open(incidentDialog.get(ctx), {
      title: '事件坐标',
      width: 560,
      height: 280,
    })
    void presentation.closed.then(() => {
      presentation = undefined
    })

    return {
      async dispose () {
        await presentation?.close()
        await player.dispose()
      },
    }
  },
})
```

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 弹窗尺寸不对 | 宿主对宽高有最小值和视口限制；界面内用弹性布局适配 |
| 按 ESC 或点标题栏关闭后业务状态没更新 | 监听 `presentation.closed` 同步状态 |
| 音频不响 | 检查是否在用户手势回调里 `play()`、服务端 CORS 是否配置 |
| 复制失败 | 剪贴板只写纯文本且可能失败；保留可选中文本兜底 |
| `hideHeader` 后关不掉弹窗 | `hideHeader` 同时隐藏了关闭按钮；界面必须自带关闭方法 |
