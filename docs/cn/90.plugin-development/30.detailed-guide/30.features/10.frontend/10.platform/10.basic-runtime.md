# 基础运行时：HTTP、事件、WebSocket 与存储

这四项是插件的地基能力：调后端接口、订阅平台事件、收业务消息、存本地数据。它们适用于全部四个宿主，且不经过 `ctx.capabilities.get()`——直接用 `ctx` 上的成员。清单里仍要声明对应权限。

> `fh2-plugin-sdk` 是插件开发 SDK；下文模块名用于说明，实际导入路径保留生成工程配置。模块名不表示已发布的 npm 包名。

## `platform:http`：调用后端接口

| 项 | 值 |
| --- | --- |
| 权限名 | `platform:http` |
| 插件 API | `ctx.apiCall<T>(endpoint, options?)` |

```ts
const health = await ctx.apiCall<{ code: number; data: { cursor: string } }>(
  '/monitor/health',
  { timeoutMs: 5000 },
)
```

`options` 字段：

| 字段 | 说明 |
| --- | --- |
| `method?` | `GET` / `POST` / `PUT` / `PATCH` / `DELETE` |
| `body?` | 相对路径：`JsonValue`、`Blob`（≤10MB）或受控 multipart；绝对 URL：仅 `JsonValue` |
| `timeoutMs?` | 超时毫秒数 |
| `idempotencyKey?` | 映射为网关 `Idempotency-Key` 请求头；长度 1–256、非空、不含换行，实际去重语义以后端契约为准 |

受控 multipart 的形状是 `{ kind: 'multipart', fields?: Record<string, string>, files: Array<{ field, name, contentType?, blob }> }`；`field`、`name` 必须是非空字符串，`blob` 必须是 Blob 或 File；最多 8 个文件、单文件 10 MiB、总文件 20 MiB。

限制与行为：

- `endpoint` 可以是单个 `/` 开头的平台内部相对路径，不能自带 `/plugin-api` 前缀、反斜杠、fragment 或路径穿越；也可以是 HTTP(S) 绝对 URL，请求经宿主网关出网并受动态白名单约束，不能带 userinfo 或 fragment。
- GET 不能带 body。
- 相对路径请求经插件网关转发到平台内部接口；绝对 URL 请求也经宿主网关出网。返回值是 JSON 原始响应，**不会**自动提取 `data`。
- 插件请求失败不会触发宿主的全局登出。
- Entry 会拦截裸 `fetch`、XHR 和新建 WebSocket，不能替代 `apiCall`；这些 Guard 错误不是 `PLUGIN_NETWORK_BLOCKED`。`PLUGIN_NETWORK_BLOCKED` 表示 `apiCall` 参数校验失败。
- 宿主卸载会取消进行中的请求。

## `platform:events`：订阅平台事件

| 项 | 值 |
| --- | --- |
| 权限名 | `platform:events` |
| 插件 API | `ctx.events.on(name, handler): Promise<AsyncDisposable>` |

平台事件目录是封闭的，只有两个（都由驾驶舱发布）：

| 事件名 | payload |
| --- | --- |
| `cockpit.emergency-stop` | `{ timestamp: number; source?: string }` |
| `cockpit.live.lifecycle` | `{ phase: 'started'\|'first-frame'\|'stopped'\|'channel-changed'; liveId: string; cameraIndex: string\|null; timestamp: number }` |

注意：

- 事件不缓存、不重放，订阅之前发生的事件拿不到。
- `first-frame` 才是逐帧处理的安全起点，`started` 只表示建联。
- 计划、消息、项目宿主当前不发布平台事件；只使用目录里的事件名。

## `platform:websocket`：订阅业务消息

| 项 | 值 |
| --- | --- |
| 权限名 | `platform:websocket` |
| 插件 API | `ctx.ws.onBizCode<T>(bizCode, handler): Promise<AsyncDisposable>` |
| 消息形态 | `{ bizCode, subBizCode: string\|null, timestamp: number\|null, data }` |

```ts
await ctx.ws.onBizCode<{ task_id: string }>('task_changed', ({ data, timestamp }) => {
  ctx.logger.info('任务变化', { taskId: data.task_id, timestamp })
})
```

这是**只读订阅**：插件不能建连、不能发送、不能控制重连，宿主只是把自己收到的消息转发给你。`bizCode` 必须非空且无首尾空格。没有可用的宿主 WebSocket 时订阅不会收到数据，业务上要保留轮询或手动刷新的降级路径。

## `platform:storage`：本地存储

| 项 | 值 |
| --- | --- |
| 权限名 | `platform:storage` |
| 插件 API | `ctx.storage.local`、`ctx.storage.session`、`ctx.blobs` |

```ts
await ctx.storage.local.set('last-seen-task', { taskId: 't-1' })
const saved = await ctx.storage.local.get('last-seen-task')

const report = new Blob([JSON.stringify({ ok: true })], { type: 'application/json' })
await ctx.blobs.put('latest-report.json', report)
const url = await ctx.blobs.url('latest-report.json')
```

- `local` / `session` 都有 `get(key)`、`set(key, JsonValue)`、`remove(key)`、`keys()`；值必须是可 JSON 序列化的。
- `blobs` 有 `get(key)`、`put(key, Blob)`、`remove(key)`、`url(key)`；`url()` 返回的 Object URL 由平台登记管理，删除或覆盖后自动失效。
- 配额：每个 KV 命名空间 256 KiB；Blob 单项 ≤50 MiB，同一命名空间最多 200 项、总量 50 MiB、TTL 24 小时，超限按最旧项淘汰。
- `local` 跨浏览器会话保留，`session` 跟随浏览器会话；两者都是插件私有的，不是跨宿主共享数据库。
- 读失败降级为 `undefined` / 空 keys 并记录诊断；写失败会抛错。

## 集成片段

先按[第一个前端插件](../../../20.development/40.hands-on/20.first-frontend-plugin.md)建立可运行工程。下面不是完整的 `fh2-plugin.json`，不可整份替换：将 `permissions` 去重合并到现有清单，保留现有宿主扩展、界面声明/注册和入口。权限不会触发激活；清单若只有 `extensions: []`，`activate()` 不会执行。

合并到 `fh2-plugin.json` 的字段：

```json
{
  "permissions": [
    "platform:http",
    "platform:events",
    "platform:websocket",
    "platform:storage"
  ]
}
```

下面的 `definePlugin` 只示范入口逻辑组织，不是可直接替换完整工程的入口；保留生成工程的 SDK 导入路径，将能力逻辑合入已有 `activate` 和业务收尾，保留原有扩展贡献与界面注册。`/monitor/health` 和 `task_changed` 需由你的业务后端提供。

```ts
// plugin.ts
import { definePlugin } from 'fh2-plugin-sdk'

export default definePlugin({
  async activate (ctx) {
    const saved = await ctx.storage.local.get('last-seen-task')
    ctx.logger.info('恢复任务游标', { saved: saved ?? null })

    const health = await ctx.apiCall<{
      code: number
      data: { cursor: string }
    }>('/monitor/health', { timeoutMs: 5000 })
    await ctx.storage.session.set('health-cursor', health.data.cursor)

    const wsSubscription = await ctx.ws.onBizCode<{ task_id: string }>(
      'task_changed',
      async ({ data, timestamp }) => {
        await ctx.storage.local.set('last-seen-task', {
          taskId: data.task_id,
          timestamp,
        })
      },
    )

    const eventSubscription = ctx.host.id === 'cockpit'
      ? await ctx.events.on('cockpit.live.lifecycle', ({ payload }) => {
          ctx.logger.info('直播状态变化', payload)
        })
      : undefined

    const report = new Blob([JSON.stringify(health)], { type: 'application/json' })
    await ctx.blobs.put('latest-health.json', report)
    const reportUrl = await ctx.blobs.url('latest-health.json')
    ctx.logger.debug('本地报告已生成', { reportUrl: reportUrl ?? null })

    return {
      async dispose () {
        await wsSubscription.dispose()
        await eventSubscription?.dispose()
        // local 数据按产品语义保留；临时 Blob 主动删除。
        await ctx.blobs.remove('latest-health.json')
      },
    }
  },
})
```

HTTP / WebSocket / 事件的更多细节见[HTTP、WebSocket 与平台事件](../../../20.development/10.frontend/70.http-websocket-events.md)，存储见[存储、Blob 与定时器](../../../20.development/10.frontend/80.storage-blob-timer.md)。

## 当前不可用的能力

当前 SDK 能力目录不支持 `platform:paas-event`，不得在 `permissions` 中声明或调用 `get('platform:paas-event')`；这不是“取不到提供方时返回 `undefined`”的有效能力。版本支持以目标环境的能力目录为准。不要用 `window` 全局对象或 `postMessage` 绕过。

`message:alert-popups` 也已从能力目录移除；`message.alert-popups` 则是仍然有效的消息扩展点，应在 `extensions` 声明，不是同名权限。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| `apiCall` 报 endpoint 非法 | 相对路径必须单个 `/` 开头且不带 `/plugin-api` 前缀；绝对 URL 必须是 HTTP(S)、无 userinfo/fragment 并命中出网白名单 |
| 收到的响应结构和预期不一样 | `apiCall` 返回完整 JSON 响应，取数据要自己读 `data` 字段 |
| 订阅了事件但一直不触发 | 平台事件只有驾驶舱发布，且不重放；先确认宿主和订阅时机 |
| `onBizCode` 收不到消息 | 宿主 WebSocket 未就绪时不产生数据；保留轮询降级 |
| 存储写入抛错 | 检查配额：KV 256 KiB、Blob 单项 50 MiB / 200 项 / 总量 50 MiB |
