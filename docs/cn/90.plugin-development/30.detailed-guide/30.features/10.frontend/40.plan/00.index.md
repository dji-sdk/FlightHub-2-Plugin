# 计划库宿主总览

计划宿主跑在计划页里，Entry 运行时固定为 `isolated-iframe`。插件在计划页能做的事：在飞行计划表单里加一块自定义区域（新建/复制时显示），并通过表单上下文读取当前表单内容。

计划页挂载且宿主就绪后，平台激活声明了计划扩展的插件；宿主由平台管理，插件作者不需要初始化宿主。

## 当前功能清单

| 类型 | ID | 说明 | 文档 |
| --- | --- | --- | --- |
| 能力 | `plan:form-context` | 当前计划表单的只读快照 | [表单上下文](./10.form-context.md) |
| 扩展点 | `plan.form-extensions` | 表单内的插件区域与提交钩子 | [表单扩展](./20.form-extensions.md) |

相关主题：[校验、提交与 biz_ext](./30.validation-submit-and-biz-ext.md)。

## 各模式下的行为

| mode | form-context | 扩展 UI | 提交钩子 |
| --- | --- | --- | --- |
| `create` | 可用 | 按 planType 显示 | `validate` → `onSubmit` |
| `copy` | 可用，含 `sourceBizExt` | 按 planType 显示 | 同 create；`biz_ext` 不自动继承 |
| `edit` | 可用，draft 含原任务 `biz_ext` | **不显示** | 只调用 `onEditSubmit` |
| `airport-test` | 可用 | 不显示 | 无插件参与 |
| `workflow-create` | 可用 | 不显示 | 工作流分支在插件管线前返回，不调用 |
| `workflow-edit` | 可用 | 不显示 | 工作流分支在插件管线前返回，不调用 |

## 注意事项

- 计划宿主没有提供 `platform:navigation`、`platform:location`、`platform:notification`，相关功能在这里隐藏。
- 主应用提供的平台能力（WPMZ、弹窗、地图等）仍可按[能力可用矩阵](../../00.index.md)获取。
- `platform:object-upload` 当前只在驾驶舱 same-origin 运行环境提供，计划宿主不可用。
- 宿主卸载时会先释放扩展、界面和上下文订阅，再销毁页面；插件管线失败时不会发出原生任务请求。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 编辑已有计划时看不到插件区域 | 正常——edit 模式不渲染扩展 UI，只执行 `onEditSubmit` |
| `platform:navigation` 是 `undefined` | 计划宿主不提供该能力 |
| 提交后没有生效 | 检查 `validate` 是否返回了 invalid，或 `onSubmit` 的补丁与原生字段冲突 |
