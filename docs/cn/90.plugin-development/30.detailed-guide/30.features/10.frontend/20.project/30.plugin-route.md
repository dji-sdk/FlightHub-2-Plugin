# 项目插件路由

插件路由不是独立的扩展点：你在 `project.sidebar-actions` 清单里声明的 `path` 会自动注册成一条项目路由，页面内容就是这个扩展的 `render()` 返回的界面。也就是说，声明了侧边栏入口，就自动获得了插件页面。

## 怎么工作

1. 清单里声明静态路径 `path`（安装后不可改）。
2. 宿主按扩展自动注册路由，并把路由和扩展关联起来。
3. 用户点击侧边栏入口或直接打开子路径时，宿主把 `render()` 返回的界面挂到项目左侧主面板。
4. 宿主会为插件页提升浮层层级，插件里的弹层不会被页面收缩把手遮挡。

真实界面在项目页左侧主面板，与项目侧边栏相邻，**不是**右侧地图工作区；需要右侧满幅内容时额外实现同一扩展的可选 `renderWorkspace()`，见 [工作区](./40.workspace.md)。

## 路由与导航示例

清单声明静态路径：

`fh2-plugin.json（节选）`：

```json
{
  "extensions": [
    {
      "id": "inspection-route",
      "point": "project.sidebar-actions",
      "path": "/inspection"
    }
  ]
}
```

界面里拿不到宿主路由器；页面跳转用 `platform:navigation` 能力：

```ts
// plugin.ts（节选）
export async function activateProject (ctx) {
  const navigation = await ctx.capabilities.get('platform:navigation')

  await inspectionView.handle(ctx, {
    state: inspectionState,
    methods: {
      openRecord: async ({ id }) => {
        if (!navigation) throw new Error('当前项目宿主不支持导航')
        await navigation.open(`/inspection/records/${encodeURIComponent(id)}`, {
          target: 'self',
        })
      },
      back: async () => {
        if (!navigation) throw new Error('当前项目宿主不支持返回')
        await navigation.back()
      },
    },
  })

  await ctx.extensions.contribute('inspection-route', {
    icon: 'inspection',
    label: '巡检',
    disabled: false,
    showBadge: false,
    render: () => inspectionView.get(ctx),
  })
}
```

完整扩展还需在清单里声明 `permissions`（加 `platform:navigation`）、`views`（`inspectionView` 的资源）和 `contributes.icons`（`inspection` 图标）。完整结构见[侧边栏贡献](./20.sidebar-actions.md)。

## 注意事项

- 运行时参数放在 `path` 的子路径、query 或 hash 里，不要改 `path` 本身（改不了）。
- 插件停用后：路由记录仍在，但找不到扩展内容，页面显示为空；重新启用后沿用原路由，不会重复注册。
- `render()` 在每次页面挂载时调用；不要返回已被其他容器占用的界面句柄。
- 路由名称由宿主生成；插件使用清单声明的 `path`，不要依赖生成的路由名称。
- `platform:navigation` 不可用时，在界面中禁用跳转按钮，而不是直接报错。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 直接打开子路径页面为空 | 子路径对应扩展已消失（插件停用）或 path 写错；检查清单声明 |
| 两个插件 path 冲突 | 没有统一仲裁；使用插件专属前缀，避开原生路径 |
| 切换插件页面时旧页面还显示 | 正常顺序是旧界面先销毁、新界面再挂载；确认没有缓存旧挂载结果 |
| 页面里的弹层被遮挡 | 宿主已对插件页提升层级；确认界面是通过 `render()` 正常挂载的 |
