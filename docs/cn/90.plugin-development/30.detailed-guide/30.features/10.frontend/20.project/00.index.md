# 项目宿主总览

项目宿主跑在项目页里，Entry 运行时固定为 `isolated-iframe`。插件在项目页能做的事：在左侧导航加入口（点进去是一个插件页面，可选再占右侧工作区）、读取当前项目上下文、页面跳转和消息提示。

项目页挂载且宿主就绪后，平台激活声明了项目扩展的插件；宿主由平台管理，插件作者不需要初始化宿主。

## 当前功能清单

| 类型 | ID | 说明 | 文档 |
| --- | --- | --- | --- |
| 扩展点 | `project.sidebar-actions` | 左侧导航入口 + 插件路由页，可选右侧工作区 | [侧边栏贡献](./20.sidebar-actions.md) |
| 能力 | `project:context` | 当前项目/组织/用户信息快照 | [项目上下文](./10.context.md) |
| 能力 | `platform:navigation` | 页面跳转与后退 | [导航、位置与通知](../10.platform/20.navigation-location-notification.md) |
| 能力 | `platform:location` | 路由快照与订阅 | 同上 |
| 能力 | `platform:notification` | 顶部消息提示 | 同上 |

相关主题：[插件路由](./30.plugin-route.md)、[双区域工作区](./40.workspace.md)。

## 注意事项

- 扩展点目录是封闭的，项目只有一个扩展点 `project.sidebar-actions`。不存在 `project.floating-panels`、`project.workspace` 这类扩展点；右侧工作区是 `sidebar-actions` 的可选 `renderWorkspace` 方法，见[工作区](./40.workspace.md)。
- 项目 Entry 运行在 `isolated-iframe` 中；`platform:object-upload` 当前只在驾驶舱 same-origin 运行环境提供，项目宿主 `get()` 返回 `undefined` 属正常。
- 主应用提供的平台能力（地图、弹窗、WPMZ 等）仍可按[能力可用矩阵](../../00.index.md)获取。
- 宿主能力不经过清单之外的白名单：在 `permissions` 里声明对应权限名即可。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 侧边栏入口不出现 | 宿主未成功挂载（无桥接）或扩展未声明；原生项目页不受影响，属降级设计 |
| `project:context` 是 `undefined` | 权限未声明，或插件当前不在项目宿主 |
| 想在右侧主区域显示内容 | 用 `renderWorkspace`，不要找独立的工作区扩展点 |
| 切换项目后旧数据还在 | 每次挂载是独立实例，重新获取上下文，不要缓存旧句柄 |
