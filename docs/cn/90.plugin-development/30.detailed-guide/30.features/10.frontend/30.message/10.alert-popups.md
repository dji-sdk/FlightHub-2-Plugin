# 消息告警弹层

`message.alert-popups` 让插件在消息中心插入自己的告警卡片：高优先级、常驻、不自动折叠。典型用法是订阅业务消息，收到告警时把卡片亮出来。这是扩展点，在清单 `extensions` 里声明（不需要额外权限），运行时用 `ctx.extensions.contribute()` 提交。

> `fh2-plugin-sdk` 是插件开发 SDK；下文模块名用于说明，实际导入路径保留生成工程配置。模块名不表示已发布的 npm 包名。

## 字段清单

| 字段 | 层 | 说明 |
| --- | --- | --- |
| `visible` | 代码 state，默认 `false` | 是否显示卡片；`false` 关闭已显示的卡片 |
| `render()` | 代码 method，必填 | 返回卡片内容的界面 |

宿主行为：卡片按高优先级插入原生消息中心队列，不自动消失（`duration: 0`），内容宽 343 px、最大高度约一屏，超出部分内部滚动。多个插件的卡片可并存，排序由宿主决定，插件不能指定 z-index。

## 可照抄示例

`fh2-plugin.json`：

```json
{
  "id": "exp_weather_alert",
  "name": "天气告警",
  "version": "1.0.0",
  "entry": "./plugin.js",
  "permissions": ["platform:websocket", "platform:http"],
  "extensions": [
    {
      "id": "weather-popup",
      "point": "message.alert-popups"
    }
  ],
  "views": {
    "weather-card": { "entry": "./views/weather-card.js" }
  }
}
```

```ts
// plugin.ts
import {
  createViewState,
  definePlugin,
  definePluginView,
} from 'fh2-plugin-sdk'

interface WeatherCardContract {
  state: { alertId: string; title: string; detail: string }
  methods: {
    acknowledge(): void
    close(): void
  }
}
const weatherCard = definePluginView<WeatherCardContract>('weather-card')

export default definePlugin({
  async activate (ctx) {
    if (ctx.host.id !== 'message') return
    const state = createViewState<WeatherCardContract['state']>({
      alertId: '',
      title: '',
      detail: '',
    })
    let popup: {
      update(patch: { visible?: boolean }): Promise<void>
    } | undefined

    async function hide () {
      await popup?.update({ visible: false })
    }
    await weatherCard.handle(ctx, {
      state,
      methods: {
        async acknowledge () {
          // 处理回执由插件自己的后端接口完成
          const { alertId } = state.get()
          await ctx.apiCall(`/weather-alerts/${encodeURIComponent(alertId)}/ack`, {
            method: 'POST',
            body: { result: 'acknowledged' },
            idempotencyKey: `weather-ack-${alertId}`,
          })
          await hide()
        },
        close: hide,
      },
    })

    popup = await ctx.extensions.contribute('weather-popup', {
      visible: false,
      render: () => weatherCard.get(ctx),
    })
    const wsSubscription = await ctx.ws.onBizCode<{
      id: string
      title: string
      detail: string
    }>('weather_alert', async ({ data }) => {
      state.update(() => ({
        alertId: data.id,
        title: data.title,
        detail: data.detail,
      }))
      await popup?.update({ visible: true })
    })

    return {
      async dispose () {
        await hide()
        await wsSubscription.dispose()
      },
    }
  },
})
```

## 注意事项

- 相同扩展不重复开卡：`visible` 从 `false` 切到 `true` 才创建卡片，重复置 `true` 不会开第二张。
- 用户手动关闭卡片后，扩展的 `visible` 可能仍是 `true`；业务要再次显示时，先显式置 `false` 再置 `true`。
- 宿主不会把消息内容传给 `render()`；告警数据由入口代码通过界面状态提供（示例里是 WebSocket 订阅）。
- 消息宿主卸载时会先关闭所有插件卡片，再销毁页面。
- 更多完整示例见[消息告警示例](../../../50.examples/11.message-alert.md)。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 收到消息但没开卡 | 确认已 `contribute` 且 `visible` 置了 `true`；重复置 `true` 不会重复开卡 |
| 用户关掉卡片后再也打不开 | 手动关闭不会同步扩展状态；先 `false` 再 `true` |
| 卡片内容太长被截断 | 内容区超出最大高度会内部滚动；不需要滚动则压缩内容 |
| 回执失败 | 保留卡片并显示可重试状态；回执只依赖你自己的后端接口 |
