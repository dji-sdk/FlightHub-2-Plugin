# 消息宿主总览

消息宿主运行在消息中心里，Entry 运行时固定为 `isolated-iframe`。插件可以在消息页插入自己的告警卡片、跳转页面和显示顶部提示。

消息中心挂载且宿主就绪后，平台会激活声明了消息扩展的插件。宿主只在主应用的 `/organization`、`/user-center` 相关路径挂载，不是全站常驻。

## 可用能力

| 类型 | ID | 说明 | 文档 |
| --- | --- | --- | --- |
| 扩展点 | `message.alert-popups` | 在消息中心插入插件告警卡片 | [告警弹层](./10.alert-popups.md) |
| 能力 | `platform:navigation` | 页面跳转（`open` 委托主应用，`back` 走浏览器历史） | [导航与通知](./20.navigation-and-notification.md) |
| 能力 | `platform:notification` | 顶部消息提示 | 同上 |

消息宿主不提供 `platform:location`，不要在这里做路由感知；`platform:object-upload` 也只在驾驶舱同源运行环境提供。其他平台能力按[能力可用矩阵](../../00.index.md)获取。

## 关闭卡片与回执

- **关闭卡片**：更新扩展的 `visible: false`。
- **处理回执**：调用插件自己的后端接口。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 卡片不出现 | 消息宿主只在 `/organization`、`/user-center` 路径挂载；换到其他页面验证不到 |
| `platform:location` 是 `undefined` | 消息宿主不提供该能力，属预期 |
| 消息中心初始化失败影响原生功能 | 不会：宿主失败时原生消息中心照常工作，插件入口不出现 |
