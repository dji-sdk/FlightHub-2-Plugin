# 场景几何与直播指针

这一页讲两个通常配合使用的坐标类能力：`cockpit:scene-geometry`（画面坐标 ↔ 地理坐标双向投影）和 `cockpit:live-pointer`（直播画面指针租约）。典型组合是"在直播画面上画框标注，并把框转成地理坐标"。

两个能力都要在清单里声明同名权限，获取后判空使用。

## cockpit:scene-geometry：坐标互投

### 方法

```ts
// 实时投影：用调用时刻的几何
projectVideoToGround(points, { groundHeight }): Promise<{ capturedAt; points: (GeoPoint | null)[] } | null>
projectGeoToVideo(points): Promise<{ capturedAt; points: ({ x, y } | null)[] } | null>

// 快照投影：用截图时刻冻结的几何
projectSnapshotVideoToGround(snapshotId, points, { groundHeight }): Promise<Result | null>
projectSnapshotGeoToVideo(snapshotId, points): Promise<Result | null>

releaseSnapshot(snapshotId: string): Promise<void>
```

画面坐标是有效视频画幅内的归一化 `{x, y}`（0~1，不含黑边）；地理坐标是 `{ lng, lat, height }`。`groundHeight` 由你的业务提供（平台不算地形高程）。

### 两种快照语义

| 用哪组方法 | 用的几何 | 适用场景 |
| --- | --- | --- |
| `projectVideoToGround` / `projectGeoToVideo` | 调用那一刻的实时几何 | 实时指示、短暂交互 |
| `projectSnapshotVideoToGround` / `projectSnapshotGeoToVideo` | `camera.captureFrame()` 返回的截图时刻几何 | 截图标注、同帧证据、延后投影 |

快照 ID 是不透明字符串，只在你自己的插件范围内有效。ID 不存在、已释放、属于其他插件、或被容量淘汰时返回 `null`；一批点里个别点投不出去时该位置为 `null`，不影响其他点。

### 快照管理

- 快照全局最多 64 个，超出淘汰最旧；没有自动过期，**用完要主动 `releaseSnapshot()`**（对未知 ID 重复释放是安全的空操作）。
- 插件运行时结束和宿主卸载会自动清理你名下的快照。

### 示例：截图中心的地理坐标

```ts
const camera = await ctx.capabilities.get('cockpit:camera')
const geometry = await ctx.capabilities.get('cockpit:scene-geometry')
if (!camera || !geometry) return

const frame = await camera.captureFrame({ scale: 1, mime: 'image/jpeg' })
const snapshotId = frame.geometrySnapshotId
if (!snapshotId) return
try {
  const result = await geometry.projectSnapshotVideoToGround(
    snapshotId,
    [{ x: 0.5, y: 0.5 }],
    { groundHeight: 0 },
  )
  if (result?.points[0]) ctx.logger.info('截图中心地理点', result.points[0])
} finally {
  await geometry.releaseSnapshot(snapshotId)
}
```

### 注意

- 能力存在不代表当前有几何：直播未出首帧、姿态数据不足、画面点没有交点，都会返回 `null`。把 `null` 当正常降级处理，不要反复重试。
- 不要调用 `cockpit:scene-raycast`；当前只有这一组双向投影方法。

## cockpit:live-pointer：指针租约

直播画面上同一时刻只能有一个插件响应鼠标操作。要处理画面的 pointer 事件，先向宿主租用指针：

```ts
interface CockpitLivePointerLease {
  stream: string
  release(): Promise<void>
  dispose(): Promise<void>
  onRevoked(handler: (reason: 'host-mode' | 'disposed') => void): Promise<Disposable>
}

acquire(stream?: string): Promise<CockpitLivePointerLease>
```

`stream` 缺省 `DronePayload`。租约只表示"你可以处理这条流的指针"，**不会自动把你的 live-overlay 变成可交互**——覆盖层的 `interactive: true` 要自己另外设置，两个都配好才有效。

### 租约会被撤销

| 撤销原因 | 含义 | 你该做什么 |
| --- | --- | --- |
| `host-mode` | 宿主进入了不允许插件占用指针的模式 | 立即停止绘制、清掉临时图形 |
| `disposed` | 句柄或插件运行时被释放 | 同上，且不要再发起新的 pointer 处理 |

收到撤销后不要尝试重新抢占形成循环；等合适的时机再 `acquire`。

### 示例

```ts
const pointer = await ctx.capabilities.get('cockpit:live-pointer')
if (!pointer) return
const lease = await pointer.acquire('DronePayload')
const revoked = await lease.onRevoked((reason) => {
  annotation.cancel(reason)
})
try {
  await annotation.drawOnce()
} finally {
  await revoked.dispose()
  await lease.release()
}
```

注意：同流冲突、未知流、SDK 状态错误会直接 reject（没有排队或"acquired: false"这种返回）；`release()`/`dispose()` 按幂等方式使用即可。

## 推荐组合：在直播画面上做截图标注

1. 等 `cockpit:context` 的 `liveReady=true`（见 [上下文与遥测](./20.context-and-telemetry.md)）。
2. 显示一个 `cockpit.ui.live-overlay` 的 `fill + interactive: true` 界面（见 [驾驶舱扩展点](./10.extension-points.md)）。
3. `acquire` 指针租约。
4. 在界面里用归一化坐标绘制；需要地理锚定时调 `scene-geometry` 投影。
5. 要出证据图时用 `camera.captureFrame()`，再按返回的快照 ID 做同帧投影。
6. 无论完成、取消、被抢占还是卸载，都释放快照、租约和订阅。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 覆盖层设了 `interactive: true` 还是收不到鼠标事件 | 没有租约；先 `live-pointer.acquire()` |
| 投影一直返回 `null` | 直播未出首帧或姿态不足；等 `liveReady`，别硬重试 |
| `projectSnapshot...` 返回 `null` | 快照 ID 无效、已释放、被 64 个容量淘汰，或属于其他插件 |
| 绘制到一半失灵 | 租约被撤销（`host-mode`/`disposed`）；监听 `onRevoked` 做清理 |
