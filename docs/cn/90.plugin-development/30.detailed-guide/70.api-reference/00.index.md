# API 参考总览

精确查语法时使用的字典，按主题分组：

本手册基线为插件开发工具 `1.0.0`、前端清单版本 `1`、平台运行协议 `1.0.0`、
后端契约 `1.1.0`。精确版本、发布日期和兼容矩阵见[发版说明](../../99.release-notes.md)；
包版本、源码发行身份和目标司空版本是不同信息，升级时再核对
[版本兼容性](./30.shared/30.version-compatibility.md)，不要只看工具链版本号。
