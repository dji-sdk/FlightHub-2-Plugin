THIRD-PARTY-NOTICES — FH2 Web IDE
================================

适用说明
--------
Web IDE 现在由源码本地构建（`pnpm --filter fh2-plugin-toolchain build:ide`，Vite）。
构建时本文件从 `ide/public/` 复制到产物根目录。

当前 1.0.0 发行包 **不含 Web IDE 预构建产物**；本文件登记的是使用方本地构建时
会打入 `dist/assets/*` 和语言服务 worker 的三方成分。使用方一旦构建并分发 Web IDE
产物，仍须随附本文件及其要求的许可证文本，不能因为“本地构建”而省略归因义务。

本文件覆盖 `ide/src` 实际 import 的第三方包：vue、pinia、@vueuse/core、
@vicons/ionicons5、@imengyu/vue3-context-menu、monaco-editor、
monaco-sql-languages、@xterm/xterm、@xterm/addon-fit、naive-ui、d3-dag、
splitpanes、@dnd-kit/vue、@dnd-kit/dom、DOMPurify、marked，以及 TypeScript
Compiler（ts.worker）。仅开发安装、未确认进入本地产物的包另列在文末。
